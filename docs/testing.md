# 测试与页面验收

ESJ Novel Downloader 是油猴脚本。自动化测试集中保护可重复验证的数据和异步边界；页面行为以真实 ESJZone 页面、浏览器和 userscript 管理器的验收为主。

## 选择验证方式

| 改动或风险                                                             | 主要验证方式                                                 |
| ---------------------------------------------------------------------- | ------------------------------------------------------------ |
| 页面注入、普通按钮操作、弹窗文案、默认状态、简繁切换、拖拽和滚动       | 实际页面验收                                                 |
| GM 权限、跨域请求、站点密码会话、文件下载触发、HTML / EPUB 阅读器显示  | 实际浏览器与 userscript 管理器验收                           |
| 范围索引、缓存兼容与迁移、所有权、锁、取消保存、并发与背压             | 聚焦的自动化边界测试                                         |
| 存储不可用、配额耗尽、事务中止、读写失败、迁移失败、锁或 writer 失效   | 注入故障的自动化测试，不能用普通页面验收替代                 |
| 损坏图片或字体、异常协议响应、导出数据与资源绑定                       | 使用合成输入的自动化测试，并按影响范围检查真实页面或导出文件 |
| 未完成决策的取消、授权中取消、旧异步结果、嵌套操作锁、输入或旧导出丢失 | 允许保留小范围 UI / adapter 自动化边界测试                   |

先复用已有用例。只有现有测试不能保护具体边界、且合成环境能够可靠重现时，才新增自动化用例。普通页面缺陷在任务或 Pull Request 中记录实际复现步骤和验收结果；不因修复缺陷、拆文件或提高覆盖率自动补测试。

同一输入、动作和结果只保留一处主要自动化证据。adapter 的普通参数转发、formatter 的展示拼接、测试替身自身规则以及精确正常阶段枚举不单独扩展测试。核心测试通过不代表页面接线已经通过。

## 测试目录

- `tests/download/`：范围、重试、完整性、调度、决策队列、取消与收尾边界。
- `tests/cache/`：真实持久化契约、兼容与迁移、写入所有权、锁、跨页状态和存储失败。
- `tests/mapping-font/`：`content/mapping-font.ts` 的严格解析、损坏输入、字体缓存规范化与恢复。
- `tests/export/`：导出数据、`content/image-format.ts` 的图片契约、字体资源、旧结果隔离与生成失败恢复。
- `tests/ui/`：少量异步决策、状态保留、资源上限及操作锁边界。
- `tests/infrastructure/`：密码协议、请求互斥、诊断数据和语言目录结构。
- `tests/stress/`：代表性的规模和资源边界。
- `tests/support/` 与 `tests/setup.ts`：实际测试使用的 fakes、fixtures、异步控制与环境清理。

所有目录属于同一个 Vitest 测试包。`*.test.ts` 用于聚焦逻辑，`*.contract.test.ts` 用于跨边界契约，`*.characterization.test.ts` 保留已经确认的复杂业务分支。文件和 `describe` / `it` 名称使用英文，标题只描述用例实际证明的结果。

## 自动化边界

修改下载、缓存或取消规则时，按影响范围选择以下已有场景：

- 全本与范围使用绝对章节索引、共享书籍锁；范围成功保留范围外缓存章节并关闭 writer。
- 预览只读；认领在事务中检查兼容和失效同意；重新确认前释放锁。
- 普通取消有界保存，停止清除可以升级；网络取消不误中止允许的缓存写入。
- 写入失败、锁或所有权丢失不会宣称保存成功；重复取消和清理失败仍能收尾。
- 新任务失败或取消保留旧导出；旧回调、同步事件和导出生成不会改写新任务。
- 密码拒绝保持可重试，不成为普通失败或缓存章节；密码和令牌只留任务内存。
- 映射字体与缺章决策串行；缺章占位仅进入导出快照。
- EPUB 设置改变使派生 Blob 失效；已完成导出和诊断仍归属原任务，无来源身份的旧结果不回写后来任务。
- 诊断 GM 读取、写入和设置快照失败不阻断调用方；终态优先于补充收尾，pagehide 与界面刷新监听各自释放。
- 诊断中性持久数据与调用时展示分离；保留容量、脱敏及 UI 日志截断的主要证据。

不为每个入口和普通成功路径复制整套矩阵。涉及实际资源清理时，检查该测试调用的 timer、listener、channel、数据库或锁；测试追踪器只能检查已经登记的资源，不能据此宣称所有生产资源都无泄漏。

存储失效和竞态属于业务边界。错误分类的单元测试只证明分类规则；还应保留受影响路径中重试、失败传播、旧数据保护和任务收尾的主要证据。普通浏览器使用不能可靠制造这些故障，精简测试时不能因已安排人工验收而删除其唯一证据。

UI 边界测试允许检查决策结果、取消后 Promise 结束、是否允许操作、输入和用户文本保留、操作锁与清理。禁止固定整页快照、CSS 类、颜色、字号、像素尺寸和排版字符串，也不复制完整界面文案或用被测 formatter / `t()` 生成 expected。语言目录保留键集合和插值检查，台湾用语由人工审阅。

资源上限和导出字体 shaping 属于业务契约。检查上限、完整数据和资源引用关系，避免固定具体批次数、packing 或内部让出次数。压力测试只保留有可观察规模差异的代表场景：

- 大量缓存章节的预览不读取正文或 Blob，且未确认时不转移 writer。
- 大图片 Blob 触发字节预算控制。
- 大缓存只重抓错误图片或旧 MIME 项。
- 大量缓存章节中的末段范围导出保持绝对索引和范围外缓存隔离。
- 慢写期间限制后续处理推进，释放后完整结束。

core / buffer 使用 fake repository 的场景只证明调度与资源控制；只有实际连接 fake IndexedDB 的用例才提供数据库契约证据。提交尝试不能当作落盘成功，也不能把大循环称为已测量的浏览器时间或内存上限。

## 隔离与异步

- 纯逻辑默认使用 Node；仅需要 DOM、DOMParser、导出文档结构或 UI 边界时启用 jsdom。
- 使用合成 fixtures 和统一 GM mocks，不访问实时 ESJZone、真实网络或生产 IndexedDB。
- 使用 `createDeferred()` 控制完成顺序，心跳、重试、超时和延迟 flush 使用 `useFakeClock()`。
- 通过请求或结构化状态控制竞态，不解析本地化日志来判断阶段。
- 每例创建独立状态，消费或清除 fake timers，关闭该用例创建的 channel / 数据库。
- 断言实际交给业务的对象及独立业务预期，避免检查从未被使用的局部变量或共同实现生成的 expected。

## 自动化验证命令

迭代时运行受影响的保留用例，提交前执行 `npm run build`。它包含 TypeScript、普通测试、ESLint、格式检查和 userscript 构建，不包含压力测试。

下载调度、缓存、迁移、锁、跨页同步、并发或取消的改动，额外执行 `npm run test:stress`；精简这些测试时也运行剩余压力套件。发布候选需要两项检查。

`npm run build:fast` 仅用于本地迭代构建，不作为提交、CI 或发布完成证据。局部测试、完整构建、压力测试和实际页面验收分别记录，未执行项写明未验证。

## 实际页面验收

普通页面行为集中通过此清单检查，不再逐项复制为 jsdom 或另一套浏览器 fixture 测试。按变更选择相关场景，发布候选检查全部适用项。源码版本、浏览器、userscript 管理器版本、场景和结果只记录在任务或 Pull Request 中；仓库文档保留通用规则与清单，不保存验收流水、通过状态或待验收记录。

| 场景                       | 实际检查                                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------------------- |
| 详情页、论坛列表页、单章页 | 下载与设置入口正确，保留原生控件；普通正文、正文晚到、原生密码解锁和正文转换后的操作状态正确            |
| 全本、范围、续传、再次导出 | 选择、缓存预览、缓存章节数提示、范围位置和文件名正确；旧结果仍可再次导出                                |
| 密码、字体与缺章决策       | 提交、拒绝、重连、跳过、跳过全部、重试、占位、继续和取消均可操作；原站 206 提示保持原文；映射字体禁 TXT |
| 停止与跨页冲突             | 普通停止、停止清除、保存中升级清理、同书互斥和远程接管的提示与实际结果一致                              |
| 三种格式和图片             | 下载确实触发；封面、正文图片、字体和章节导航在实际 HTML / EPUB 阅读器中正确；插图关闭时字体仍正确       |
| 设置和语言                 | 偏好保存，自动语言跟随站点；开放弹窗、输入和操作状态更新正确；台湾用语人工审阅；EPUB 设置改变后结果重建 |
| 历史、缓存与诊断           | 查看、筛选、刷新、单条删除、清空确认、再次导出、诊断 JSON 下载与摘要复制可用                            |
| 消息和界面交互             | 错误、保存超时、清理失败、图片失败提示可读；弹窗关闭、最小化、拖动、列宽与滚动正常                      |
| 主流程维护                 | 从 `docs/architecture.md` 的入口定位数据来源、阶段、退出以及密码 / 缓存规则                             |

合成 GM shim 和浏览器 fixture 可用于调试，但不算真实扩展验收。页面验收使用真实浏览器与 userscript 管理器，例如 Chrome + Tampermonkey 或 Firefox + Violentmonkey；任务或 Pull Request 中只描述实际验证过的组合与范围。
