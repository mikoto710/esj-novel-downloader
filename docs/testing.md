# 测试与页面验收

## 验证命令

- 日常迭代先运行受影响的 Vitest 用例。提交前执行 `npm run build`，依次检查 TypeScript、普通测试、ESLint、Prettier 并构建 userscript。`npm run build:fast` 仅用于迭代。
- 改动调度、缓存、迁移、写入权、跨页同步或取消时，加跑 `npm run test:stress`。发布候选须执行完整构建、压力测试及适用的实页验收。
- 在任务或 PR 中记录候选版本、实际执行的检查、浏览器和脚本管理器版本，以及尚未验证的场景。仓库指南保留通用检查方法。

## 按改动选择用例

| 改动               | 测试目录与观察结果                                                                                                                                                                                    |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 选择、恢复和完整性 | `tests/download/` 检查绝对索引、稀疏选择、旧摘要、补抓、密码和缺章决策。未选章节不参与恢复或占位。进度区分就绪与已提交。                                                                              |
| 章节身份与迁移     | `tests/cache/` 覆盖插章、调序、同名异章、站外目标更换和旧数据缺少标识。验证 v3 预览只读、旧缓存按需重抓、插图不兼容需确认、v3 清除标记优先。                                                          |
| 写入权与取消保存   | 用 fake IndexedDB 核验新任务取得锁但尚未认领缓存时旧任务已无法写入。通过真实下载入口触发 `pagehide`，在下一任务中读回已提交正文。验证普通取消、保存超时、停止清除、迟到的远程确认和缓存列表局部失败。 |
| 下载结果与错误     | `tests/download/` 和 `tests/cache/` 注入配额、事务中止、读写及释放失败。验证正文未提交时报告失败，已完成全本遇清理故障仍可导出。失去所有权或丢弃时保留上一次结果。                                    |
| 章节请求与诊断     | `tests/infrastructure/`、`tests/download/` 覆盖登录响应、缺正文、密码拒绝与重试、同源授权、GM 空响应和取消。检查新旧诊断文本和结构化字段脱敏、升级迁移及跨任务归属。                                  |
| 正文、图片和导出   | `tests/mapping-font/`、`tests/export/` 检查 TXT 换行与标题、正文阅读排版、图片 MIME、映射字体和损坏资源。解析最终 HTML、EPUB 及 OPF，核对正文、资源引用、UTC 修改时间、文件名及再次导出。             |
| 弹窗与语言         | `tests/ui/` 集中保护异步决策、操作锁、搜索和勾选保留。`tests/infrastructure/locale.test.ts` 检查简繁键与插值。控件布局与台湾用语在实际页面核对。                                                      |
| 大目录与资源上限   | `tests/stress/` 检查大量章节的预览不读取正文或 Blob、稀疏与末段范围、旧图片修复、大 Blob 字节预算和慢写背压。断言可观察的数据及资源边界。                                                             |

## 自动化约定

- 优先复用已有用例。按能观察到失败的入口增加回归，同一输入、操作和结果保留一处主要证据。纯逻辑用 Node，DOM 或导出文档结构用 jsdom。测试文件、`describe` 和 `it` 使用英文描述实际验证的行为。
- 下载入口测试先导入[浏览器下载测试工具](../tests/support/browser-download-harness.ts)注册替身，再导入应用模块。核心流程复用[下载内核测试工具](../tests/support/download-harness.ts)。字体解析、缓存和单章导出共用[合成映射字体](../tests/support/mapped-font-fixture.ts)。用 `createDeferred()` 或结构化状态控制先后顺序。每例独立持有状态，结束时等待异步工作并清理所建定时器、监听、频道、数据库和锁。
- 缓冲与调度可用假仓库验证背压；提交、迁移和接管须由连接 fake IndexedDB 的契约验证。注入故障后检查失败传播、旧数据及新任务的实际结果。自动化测试只使用合成内容和模拟网络。
- UI 断言关注可操作性、用户输入、决策和清理。避免固定整页快照、CSS 类名、像素值、完整文案、内部批次数及具体调度次数。预期值独立于被测实现。

## 实际页面与导出验收

按改动在真实浏览器和 userscript 管理器中选取场景。合成页面可稳定控制晚到节点、窄屏和大目录；站点会话、GM 权限、文件触发及阅读器显示分别记录实测结果。

| 场景             | 实际检查                                                                                                                                                     |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 页面与准备       | 检查详情、论坛列表和单章页的下载入口。容器在启动后 30 秒内出现时，按钮可用且原站控件保序。慢网下可取消或打开旧导出，重试及正文晚到能恢复。                   |
| 全本与自选       | 勾选连续或稀疏章节，切换全选、搜索、语言和文件名。在窄屏使用进度及缓存窗口。核对选择、断点、最近结果和实际导出顺序。                                         |
| 批量兼容模式     | 登录后分别关闭、开启兼容模式下载同一未缓存章节。确认设置保存后在下次任务生效，并核对章节正文、正文插图和密码章节。                                           |
| 交互与跨页       | 密码拒绝、重连和原站协议提示，映射字体与缺章决策，普通停止、停止清除、跨页接管及迟到确认。对照缓存管理提示和下一任务能读回的内容。                           |
| 文件与阅读器     | 实际下载 TXT、HTML、EPUB。对照章数、标题、换行、导航和原始书名，离线打开富文本检查封面、正文插图、作者排版及适用字体。分别记录文件结构检查与阅读器显示范围。 |
| 设置、历史与诊断 | 检查偏好保存、简繁切换及台湾用语，历史筛选、删除、再次导出，缓存刷新与清理，诊断复制、JSON 和两域隔离。核对错误提示、拖动与滚动。                            |

## 人工交接走读

由未参与改动的维护者从 README、[贡献指南](../CONTRIBUTING.md)、[架构指南](architecture.md)及源码定位重试、标题去重、缓存恢复与取消、密码重连、缺章、双语文案和 EPUB 元信息与命名。目标是 10 分钟内定位、30 分钟内解释输入、退出和主要测试。在任务或 PR 记录实测时间、经过的业务文件及需要绕行的回调或转发。
